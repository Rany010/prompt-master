# Prompt Master

## Project Setup

```bash
# Install dependencies
pnpm install

# Start development server for web app
pnpm dev:web

# Start development for Chrome extension
pnpm dev:extension

# Build for production
pnpm build:web
pnpm build:extension
```

## Project Structure

```
packages/
  ├── web/         # Web application
  └── extension/   # Chrome extension
```

## Technologies Used

- Vue 3
- Vite
- TailwindCSS
- Naive UI
- TypeScript
